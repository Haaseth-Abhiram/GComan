## Execution order — best return first

### 1. Bing Places — FREE, fastest, fixes a confirmed gap ⭐ do this first
- **Why:** Bing ranks gcoman.com **#1 organically** for the category head term, yet you are **absent from Bing's local map pack** (Muscat Chemicals / Sohar / Oman Chem own it) — verified 2026-09-28.
- **The shortcut:** Bing Places can **import your existing Google Business Profile** — name, address, phone, hours, categories, photos, description in one step. Because your GBP is already verified (5.0★), this normally qualifies for instant/fast verification rather than a postcard.
- **Do:** [bing.com/forbusiness](https://www.bing.com/forbusiness/) → sign in → choose **"Import from Google My Business"** → connect the Google account that owns the GBP → enable periodic auto-sync.
- **Cost:** free. **Time:** ~10 min; verification 24–72h.
- **Note:** sign in with the same `globalchemicalsllc8@gmail.com` identity you use for Bing Webmaster (see memory — that account is Google-OAuth linked, there is no Microsoft password).

### 2. Dun & Bradstreet (D-U-N-S) — FREE, highest strategic value ⭐
- **Why:** D&B is a *root* record that many other directories and data providers inherit from. The other company already holds a D&B profile. This is the single most effective disambiguation action available.
- **Do:** [dnb.com — Claim your free D-U-N-S](https://www.dnb.com/en-us/smb/duns/get-a-duns.html). First **[look up existing records](https://www.dnb.com/en-us/smb/duns/duns-lookup.html)** for "Global Chemicals" in Oman.
- **Cost:** free (expedited ~8 business days is paid). **Time:** ~20 min; **standard issuance up to 30 business days** — start it today precisely because it is the slowest.
- **⚠️ Critical:** do **not** request a second number if one already exists — duplicate D&B records are painful to unpick. If you find duplicates, contact D&B and ask them to consolidate.

### 3. Made in Oman Gate — FREE, direct competitor parity
- **Why:** competitor MBBT/Muscat Chemical is [listed here](https://madeinomangate.com/factories/muscat-chemical-company-mbbt/) and you are not. Run by FGCC; an Oman-manufacturing platform, so topically ideal.
- **Do:** use the **"Register as Vendor"** link on the site. Queries: `info@madeinomangate.com` / **+968 9740 0082**.
- **Cost:** appears free. **Time:** ~15 min.

### 4. Metoree — FREE-looking, competitor parity
- **Why:** Bing counts **9 links** from metoree.com to muscatchemical — one of their few genuine third-party sources. Profiles carry company overview, country, website and product listings.
- **Do:** use **"Claim Your Company"** in the site header. Check first whether a stub profile for you already exists to claim (faster than creating one) — note [Global Chemical Co., Ltd.](https://us.metoree.com/companies/191952/) and [Global Chemical Resources](https://us.metoree.com/companies/159721/) are **different companies — do not claim those.**
- **Time:** ~15 min.

### 5. OmanYP — PAID, but this is the identity fix
- **Why:** the three-listings-vs-zero problem above.
- **Do:** [omanyp.com/create-business-listing](https://www.omanyp.com/create-business-listing) → **"+ Get Listed"**.
- **Cost — the one paid item:** Basic **$20 one-time** / Premium **$65 per year** / Lifetime **$145 one-time**.
- **My recommendation: Basic at $20.** The SEO and disambiguation value is in the listing existing at all; the premium tiers buy presentation, not authority. If you want it permanent without renewals, Lifetime at $145 is defensible — but do not start at Premium.
- **Fields to have ready:** company name, address, phone/WhatsApp, email, **CR & VAT number**, description, website, Google Maps location, hours, year established, employee count, contact person.

### 6. Yellow Pages Oman — PAID, lowest priority of the six
- **Why:** appears in SERPs for "chemical suppliers in Oman" as a directory competitor, so presence has some defensive value — but it is the weakest return here.
- **Do:** contact `info@yellowpages.om` for current rates.
- **Recommendation:** **do this last, and only if 1–5 are done.** Do not let a paid listing delay the four free ones.
