# Implementation Guide

## How to Add Images to the React Components

Once you have sourced/generated images, here's how to integrate them:

### Step 1: Add Images to Project
```bash
# Create images directory structure
mkdir -p src/assets/guides/ro-desalination
mkdir -p src/assets/guides/cooling-tower
mkdir -p src/assets/guides/boiler-treatment

# Add your image files to respective directories
```

### Step 2: Import Images in Resources.tsx
```typescript
// At top of Resources.tsx
import roMembraneProcess from '@/assets/guides/ro-desalination/ro-membrane-process.webp';
import scaleFormation from '@/assets/guides/ro-desalination/scale-formation.webp';
// ... import all images
```

### Step 3: Add Image Field to Guide Structure
Modify the `IndustryGuide` interface to include images:

```typescript
interface GuideSection {
  title: string;
  content: string;
  tips?: string[];
  image?: {  // ADD THIS
    src: string;
    alt: string;
    caption?: string;
  };
}
```

### Step 4: Add Images to Guide Sections
Example for RO guide:

```typescript
{
  title: 'Understanding Anti-Scalants: What They Are and Why Critical',
  content: '...',
  image: {
    src: scaleFormation,
    alt: 'Comparison of clean RO membrane vs scaled membrane with calcium deposits',
    caption: 'Left: Clean RO membrane. Right: Membrane with severe calcium carbonate scaling reducing performance by 70%'
  },
  tips: [...]
}
```

### Step 5: Update Rendering Logic
Modify the guide display component to show images:

```typescript
{section.image && (
  <div className="my-6">
    <img
      src={section.image.src}
      alt={section.image.alt}
      className="rounded-lg shadow-md w-full max-w-3xl mx-auto"
      loading="lazy"
    />
    {section.image.caption && (
      <p className="text-sm text-gray-600 text-center mt-2 italic">
        {section.image.caption}
      </p>
    )}
  </div>
)}
```

# Optimization Best Practices

## Image Optimization for Web Performance

### Format Recommendations
- **Photos:** WebP format (70% smaller than JPG)
- **Diagrams with text:** PNG (lossless)
- **Simple graphics:** SVG (scalable, tiny file size)

### Size Guidelines
- **Maximum width:** 1600px (will scale down on mobile)
- **Target file size:** <150 KB per image
- **Total page impact:** <2 MB for all images on a guide

### Optimization Tools (Free)
- **Squoosh.app** - Google's image compressor
- **TinyPNG** - PNG/JPG compression
- **SVGOMG** - SVG optimization
- **ImageOptim** (Mac) - Batch compression

### SEO Optimization
✅ **DO:**
- Use descriptive filenames: `ro-membrane-scale-formation.webp`
- Write detailed alt text for accessibility
- Add captions explaining what viewers should notice
- Use structured data for images

❌ **DON'T:**
- Generic names: `image1.jpg`, `diagram.png`
- Missing alt text
- Oversized files slowing page load
